# SmartVision AI

Intelligent Multi-Class Object Recognition System using Transfer Learning and YOLOv8.

## Features
- 4 CNN Models (VGG16, ResNet50, MobileNetV2, EfficientNetB0)
- YOLOv8 Object Detection
- 25 COCO Classes
- Streamlit Web App
- Hugging Face Deployment

## Tech Stack
- Python
- TensorFlow
- Ultralytics YOLO
- Streamlit
- OpenCV

## Results
- Classification Accuracy: Up to 91%
- YOLO mAP@0.5: 85%+
- Real-time Inference
